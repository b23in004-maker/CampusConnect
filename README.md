# CampusConnect – Smart Campus Management System

## 📌 Overview

CampusConnect is a web-based Smart Campus Management System developed using PHP and MySQL. It provides a centralized platform where students can register for campus events, book college resources, join student clubs, and manage their profiles. An integrated Admin Portal allows administrators to monitor registrations, approve room bookings, and manage student activities.

---

## ✨ Features

### Student Portal

* Student Registration & Login
* Secure Authentication using PHP Sessions
* Dashboard with activity summary
* Register for Campus Events
* Withdraw Event Registrations
* Book Campus Resources
* Cancel Room Bookings
* View Room Booking Status (Pending / Approved / Rejected)
* Join Student Clubs
* Leave Clubs
* Update Student Profile
* Success & Error Notifications

### Admin Portal

* Secure Admin Login
* Dashboard
* View Registered Students
* View Event Registrations
* View Room Bookings
* Approve / Reject Room Booking Requests
* Delete Room Bookings
* View Club Registrations
* Delete Club Registrations

## 🚀 Installation

1. Install XAMPP.
2. Clone this repository.

```
git clone https://github.com/b23in004-maker/CampusConnect.git
```

3. Copy the project into:

```
C:\xampp1\htdocs\
```

4. Start:

* Apache
* MySQL

5. Import the SQL database using phpMyAdmin.

6. Open:

```
http://localhost/CampusConnect
```
